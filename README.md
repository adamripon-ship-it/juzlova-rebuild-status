# Juzlová rebuild — recovery status

A single-page status board for recovering the last-live version of the down
**juzlova.cz** recipe/marketing site from the Wayback Machine, packaged for a
fresh rebuild in **Webflow**.

- **Live page:** `index.html` (self-contained; light/dark; tabbed).
- **Published via GitHub Pages** — see the repo's Pages URL.
- Generated by the `project-artifact` skill; refresh by re-running that skill,
  which re-gathers live Wayback CDX state and reports the delta.

The page's machine-readable state (for computing the next refresh's delta) lives
in the `#artifact-state` `<script>` block at the bottom of `index.html`.
