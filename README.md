# Jůzlová.cz — rebuilt site

Static rebuild of **juzlova.cz** (Czech food-mix maker from Kochánov, Vysočina),
recovered from the Wayback Machine after the original WordPress site went down.

- **Live site:** the repo root, published via GitHub Pages (`index.html` + one
  directory per original URL slug, so old links keep working).
- **`status.html`** — the original recovery status board (formerly `index.html`).
- Content was recovered from captures pinned around **2025-12-09** (last-live
  state), with the 2019-03-28 capture filling gaps in recipe teasers/images.
- Images are hot-linked to their Wayback captures (`…im_/…` URLs).

## Known gaps

Full text for four pages could not be pulled during an Internet Archive outage
and currently carries teaser/placeholder copy: `sisky-s-makem-recept`,
`strapacky-se-zelim-a-slaninou-recept`,
`podle-lucie-kuzelovebebe-rezy-s-cokoladovym-pudingem`,
`bramborovo-tvarohove-knedliky-s-jahodami`. The original homepage capture was
also unavailable; the homepage is a new composition of recovered content.
