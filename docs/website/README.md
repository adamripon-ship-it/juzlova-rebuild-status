# juzlova.cz — Website Handbook

Everything about the Jůzlová website in one place: where it lives, how it is
built, what every page says, and how to change it.

> **Jůzlová** is a family food-mix workshop in Kochánov, Vysočina (Czech
> Republic). It makes potato and "chlupaté" dumpling mixes, gluten-free vanilla
> pudding, Dutch-process cocoa and vanilla sugar, sold directly from the
> workshop. Owner contact on the site: Jiřina Jůzlová, +420 728 466 141.

These are produced from the live build by `scripts/export_docs.py`. The
automatic check on every pull request refuses changes that leave them out of
date, so they always match the site.
